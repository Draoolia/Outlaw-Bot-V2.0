Politique de Confidentialité — Outlaw A.I.

Dernière mise à jour : Novembre 2026

Conformément au Règlement Général sur la Protection des Données (RGPD — Union Européenne), cette politique détaille les données collectées par Outlaw A.I. et vos droits.

1. Données collectées

  • Identifiants Discord : ID de serveur (guild_id), ID de salon (channel_id), ID de rôle (role_id) et ID d'utilisateur (user_id).
  • Configuration du serveur : langue, couleur d'interface, réglages anti-raid/DEFCON, règles, niveaux XP, flux RSS/YouTube et statut d'abonnement/essai Premium.
  • Clés API fournies par les administrateurs : stockées dans la base de données du bot uniquement pour exécuter les requêtes IA demandées sur le serveur.
  • Contenu temporaire : les textes ou images soumis explicitement aux commandes d'IA, de traduction ou d'analyse anti-arnaque (OCR) sont traités à la volée et ne sont jamais revendus.

2. Utilisation des données

Vos données sont utilisées exclusivement pour fournir les fonctionnalités du bot, prévenir les abus (anti-raid, anti-spam, unicité de l'essai gratuit de 7 jours) et gérer les accès Premium.

3. Partage avec des services tiers

Aucune donnée personnelle n'est vendue ou louée. Seules les requêtes déclenchées par les utilisateurs sont transmises aux API choisies par l'administrateur (Groq, OpenAI, Google Gemini, xAI, Anthropic) ou aux flux publics (Reddit, YouTube, GamerPower).

4. Conservation et suppression (Vos droits RGPD)

Les paramètres d'un serveur sont conservés tant que le bot est utilisé sur ce serveur (à l'exception de l'identifiant technique d'essai gratuit conservé pour prévenir les abus). Vous disposez d'un droit d'accès, de rectification et de suppression de vos données sur simple demande via notre serveur Discord support.
